# Rig Mod (Fabric, Minecraft 1.21.11, client-side only)

Build with GitHub Actions: push this folder to a GitHub repo, open the Actions tab,
open the finished "build" run and download the "rigmod-jar" artifact.

Put the jar + Fabric API (1.21.11) in .minecraft/mods, using Fabric Loader for 1.21.11.
Z = toggle (works inside the dropper GUI), X = settings menu (in the world).
